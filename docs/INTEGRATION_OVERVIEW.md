# Zybra Subgraph Integration Guide

## Overview

This documentation provides complete instructions for integrating the Zybra Money Subgraph into your backend system. The subgraph replaces database-stored yield, contribution, and investment data with real-time blockchain-indexed data.

## What Data Comes From Subgraph (REMOVE from Database)

### User Data (Replace DB queries)
- `totalContributed` - Total amount user has contributed across all groups
- `totalYieldEarned` - Total yield earned across all groups
- `totalYieldClaimed` - Total yield claimed across all groups
- `totalWithdrawn` - Total withdrawn (capital + yield)
- `activeCapital` - Currently active capital in non-ended groups
- `pendingYield` - Unclaimed yield across active groups
- `activeGroupsCount` - Number of active groups user is in
- `totalGroupsJoined` - Total groups user has ever joined

### Group Data (Replace DB queries)
- `totalCapitalInGroup` - Total capital from all members
- `totalContributions` - Sum of all contributions
- `totalYieldGenerated` - Total yield generated by the vault
- `totalYieldDistributed` - Total yield distributed to members
- `totalYieldClaimed` - Total yield claimed by members
- `membersCount` - Total members in group
- `activeMembers` - Currently active members

### Member Data (User's position in specific group)
- `capitalInGroup` - User's capital in this specific group
- `totalContributedAmount` - Total contributed to this group
- `totalYieldEarned` - Yield earned in this group
- `totalYieldClaimed` - Yield claimed from this group
- `pendingYield` - Unclaimed yield in this group

### Chart Data (Time-series for graphs)
- `UserDailySnapshot` - Daily user stats for yield charts
- `GroupDailySnapshot` - Daily group stats for TVL/yield charts
- `ProtocolDailySnapshot` - Protocol-wide daily stats

## Key Integration Points

### 1. User Dashboard
- Overall yield stats → Query `User` entity
- Yield chart → Query `UserDailySnapshot` entities
- Per-group breakdown → Query `Member` entities for that user

### 2. Group Page
- Group stats → Query `Group` entity
- Member list with yields → Query `members` on Group
- Yield history → Query `GroupDailySnapshot` entities

### 3. Yield Charts
- User yield over time → `UserDailySnapshot` or `UserHourlyYield`
- Group yield over time → `GroupDailySnapshot` or `GroupHourlySnapshot`
- Protocol yield over time → `ProtocolDailySnapshot`

## Data Flow

1. **User joins group** → `Joined` event → Subgraph creates `Member` entity
2. **User contributes** → `Contributed` event → Updates `Member`, `User`, `Group`, creates `Contribution`
3. **Yield accrues** → `YieldAccrued` event → Updates `Group.totalYieldGenerated`
4. **Yield claimed** → `YieldClaimed` event → Updates `Member`, `User`, creates `YieldClaim`
5. **User withdraws** → `Withdrawn` event → Updates all entities, creates `Withdrawal`

---

## Important Notes

1. **All addresses are lowercase** - Always convert addresses to lowercase before querying
2. **Amounts are in wei** - Divide by 10^decimals (usually 10^6 for USDC)
3. **Timestamps are Unix seconds** - Convert to Date objects as needed
4. **IDs are deterministic**:
   - User ID = lowercase address
   - Group ID = lowercase group contract address
   - Member ID = `{groupId}_{userId}`
